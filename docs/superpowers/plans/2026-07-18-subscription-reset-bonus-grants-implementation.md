# 订阅重置次数赠送实施计划

依据 `docs/superpowers/specs/2026-07-18-subscription-reset-bonus-grants-design.md` 实施。每阶段遵循测试先行：先新增并确认失败用例，再实现到测试通过；阶段完成后由常驻只读 reviewer 独立检查，阻断问题修复后再进入下一阶段。

## 1. 数据库与旧补发停用

- 在 `backend/internal/db` 新增赠送批次、批次明细、赠送权益、订阅延期事件表及索引、检查约束和幂等约束。
- 重建 `subscription_reset_attempts`，允许空 `period_id`，增加权益类型/ID，并把阻塞唯一约束改为订阅 ID。
- 为基础周期增加历史忽略字段；迁移时将旧补发任务置为 `superseded`，仅忽略未授予的历史零次数周期。
- 删除档位保存触发旧补发和后台处理旧补发的路径，新购买周期逻辑保持不变。
- 测试：新旧数据库重复迁移、旧 attempt 数据转换、正数权益保留、零次数历史周期忽略、旧任务停止。

## 2. 赠送预览、批次和 worker

- 在 `backend/internal/app` 实现输入规范化、目标用户/多分组校验、有效订阅分页筛选和无限额分组排除。
- 实现十分钟签名预览令牌，绑定管理员、输入和候选摘要；创建时重新读取并拒绝过期或变化的预览。
- 持久化批次与候选明细，worker 幂等创建绑定具体订阅的 bonus grant，并在启动和唤醒时恢复未完成批次。
- 在 `backend/internal/httpapi` 增加预览、创建、批次列表和明细接口，创建成功返回 `202`。
- 测试：全部/指定用户、多分组、外部订阅、无限额跳过、预览过期/越权/陈旧、重试不重复赠送。

## 3. 权益聚合与重置事务

- 扩展订阅卡片 DTO，聚合当前基础周期和同一订阅的有效赠送权益，返回基础、赠送、合计及赠送明细。
- 按到期时间、赠送优先、权益 ID 顺序选择扣减 bucket；外部周期有赠送次数时允许重置。
- 重置 attempt 记录实际权益来源；明确失败和人工释放归还原 bucket，未知结果保持占用，幂等重放不重新选 bucket。
- 将阻塞操作、管理员待确认查询和未知结果对账全部改为按订阅与权益来源工作。
- 测试：排序、聚合、并发只扣一次、失败归还、人工释放、外部订阅可重置、撤销/过期赠送不可用。

## 4. 补偿延期事件

- 保持现有补偿请求和表单校验不变；在每个订阅延期前后写入独立事件和权威到期快照。
- 成功延期后在单个 SQLite 事务中延长当前基础周期、平移未来周期、延长当前未过期 bonus grant，并标记事件已应用。
- 网络结果未知时不改本地权益；增加事件查询和管理员 `applied/released` 决议接口，冲突决议返回 `409`。
- 迁移既有成功补偿明细为幂等历史事件，仅把历史天数应用到当时已存在且当前仍绑定的基础周期，不延长后来新增赠送。
- 测试：成功同步延期、次数不变、重复不二次延期、明确失败、未知结果和人工决议、历史迁移重复执行。

## 5. 管理员与用户前端

- 新增独立“重置次数赠送”管理页面：用户范围、多分组、次数和备注，先预览后确认，展示批次进度及明细。
- 在管理员处置区域增加延期事件列表和 `applied/released` 决议对话框；移除旧补发运行状态操作入口。
- 用户订阅卡片展示基础次数、活动赠送、合计、赠送到期明细和下一扣减来源；保持无限额卡片等高占位。
- 扩展前端 API、类型、路由和导航，补齐组件测试；请求期间禁止重复提交。
- 测试：表单约束、预览陈旧提示、轮询、外部订阅赠送状态、移动端卡片稳定性。

## 6. 迁移、回归与交付

- 在生产变更前提供只读检查和迁移后核验查询；迁移不直接创建营销赠送批次。
- 使用新功能为确认缺失权益的用户创建定向批次，保留已经授予的历史次数，验证旧失败任务不再重试。
- 运行 `cd backend; go test -race ./...`、`cd frontend; pnpm test`、`cd frontend; pnpm build`。
- 使用 Playwright 在 1440x900 和 390x844 验证赠送页面、订阅卡片、确认框和错误状态。
- reviewer 对最终 diff、迁移安全和全量测试做独立复核；不自动推送、部署或修改线上数据。
